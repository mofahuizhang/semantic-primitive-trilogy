# 认知语义基元三论（CSMT / CCT / CART）

> **同一理论 T 的三种等价公理化（3-in-1）。**
> 静态结构（CSMT）→ 动态编码（CCT）→ 资源生成（CART）。

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21831385.svg)](https://doi.org/10.5281/zenodo.21831385)

## 一、这是什么

三论不是三套理论，是**一套理论的三种证明路径**：命题内容相同，推导起点与叙事路径不同。

| 维度 | CSMT 认知语义基元矩阵论 | CCT 认知编码论 | CART 认知注意力资源论 |
|:--|:--|:--|:--|
| **推导起点** | 义原矩阵为第一性公理（A0＋P1–P3） | 「认知＝编码」为第一性公理（A0＋P1–P3） | **注意力预算（B1）＋载体分立（B2）**为最小充分硬约束集 |
| **覆盖维度** | 静态结构 | 动态编码 | 资源生成 |
| **内核性质** | 1 公理＋3 公设 | 1 公理＋3 公设 | 2 硬约束 |

**3-in-1 元声明**：CSMT 与 CCT 以 A0＋P1–P3 为公理-公设起点；**CART 给出更深归约**——B1（注意力预算）＋B2（载体分立）为最小充分硬约束集，A0／P1–P3 是其**概念归约结论**（作者自标为 abduction，非演绎证明）。因此 CSMT／CCT 中「A0 不可推导」的表述，须限定为**针对其自身公理化的极小性**，不排斥 CART 的更深归约。

## 四、读法

1. **`docs/同源三框架-导航卷.md`** —— 三框架总览、共享主干索引、跨框架对照。**不要跳过。**
2. 按需进入某一框架的**总卷**（定位与架构）。
3. 需要推导细节，读该框架的**定义层 → 定律层 → 定理层**（逐层演绎）。
4. 需要范围与反例，读**扩展与实证**（含假设 H、探针 G、推测 𝒫）。
